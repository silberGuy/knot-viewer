## Terminology

### Drawing
The 2d data that the user creates directly.
He controls the points and the lines of the knots.
This data is controlled and displayed on the drawing-board.

### Diagram
The first interpertation of the drawing, with added points to allow the intersections to go higher
This data is converted to 3D-knots and rendered in the knots-viewer.

### Surface
The triangulation of the 3D-knot.
